# FMPS 可视化系统

FMPS（File Management and Processing Systems）的网页可视化版，

## 版本

**v0.2.0** · 2026-09-11

## 更新信息

### v0.2.0 — 2026-09-11

- **头像管理系统**：学生头像三类目录（`stu_icon_db_png` / `stu_icon_db` / `gacha-img`）统一管理，支持 schaledb 自动生成、wikiru 抓取、候选图挑选、人工上传与来源标记；带 `force` / `forceManual` 双开关，人工指定的图永不被批量流程覆盖
- **云端发布记录**：版本管理页可看到**任意设备**发布过的历史版本（COS 对象时间聚类重建 + 发布清单双通道），支持与本地现状逐文件对比、按需拉回本地。新增 COS 分页 bug 修复（`IsTruncated` 是字符串而非布尔）
- **前端视觉重构**：浅色 / 深色双主题改用 CSS 变量 token 体系，修复深色模式面板发灰、按钮白底白字；全站字号放大；表格操作列对齐
- **数据更新**：新增 `心` / `琴音` 等学生，学生总数 **272**，头像齐全率 **100%**

### v0.1.0 — 初始版本

- 学生数据管理：列表 / 详情 / 缺失高亮 / 别名自动补充
- 漫画、卡池、礼物、推图等数据管理
- 发布到 COS：红绿 diff 预览 + 独立发布密码认证
